# Blog & News Publishing Platform — Admin Role

Project P10 of WT-M Final Lab.

## My Role

**Admin** — manages user accounts and roles, oversees platform-wide content moderation, accesses analytics.

## Folder

All project code lives inside `blog-and-news-publishing-platform/`.

## Run

1. Place `blog-and-news-publishing-platform/` inside `htdocs/` of XAMPP.
2. Start Apache and MySQL from XAMPP.
3. Open `http://localhost/blog-and-news-publishing-platform/config/create.php` once to set up the database.
4. Open `http://localhost/blog-and-news-publishing-platform/app/views/auth/login.php` and log in as an admin user.

## Branch

`feature-admin` — admin role implementation (this branch).
