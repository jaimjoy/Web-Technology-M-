# Blog and News Publishing Platform

A multi-role blog and news publishing platform built with PHP and MySQL.

## Project Structure

The PHP project lives inside `blog-and-news-publishing-platform/`.

## How to Run

1. Place `blog-and-news-publishing-platform/` inside `xampp/htdocs/`.
2. Start Apache and MySQL from XAMPP.
3. Open `http://localhost/blog-and-news-publishing-platform/` in your browser.
4. Run `config/create.php` once to create the database schema.

## Database

MySQL database name: `blog_platform`. Connection settings are in `config/database.php`.
